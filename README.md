# Teatime – Englisch lernen

Eine installierbare Web-App zum Englischlernen für Anfänger: Lernpfad mit 411 Wörtern, Spiele, Geschichten und Gespräche. Läuft offline, ohne Konto.

**App öffnen:** https://vincentmks.github.io/Englisch-Lernen-App/

Auf dem iPhone den Link in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
